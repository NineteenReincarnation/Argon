# Argon Reference Baselines

Argon reference material is grouped by **Minecraft version**.

Each version directory contains the exact Fabric baseline, compatibility references, shader baseline, profiling notes, and pinned third-party source revisions used while developing that Minecraft version.

## Versions

- [Minecraft 26.2](./26.2/)

Do not mix reference material for different Minecraft versions in the same directory. When Argon moves to another Minecraft version, create a sibling directory such as `26.3/` and pin a new baseline there.

Third-party repositories are attached as Git submodules so their source, history, and licenses remain upstream-owned and version-pinned.
